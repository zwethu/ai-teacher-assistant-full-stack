Agent-thinking indicator — the living MILA garland. Distinct from `Spinner`:
use **Thinking** while the agent is working (chat runs, generation, tool calls),
and **Spinner / PageSpinner** for plain loading and waiting.

Motion (7.2 s walk): the gold insight bead steps bead-to-bead (1.2 s a step) and
the purple bead it lands on dims beneath it, so it reads as each bead turning
gold in turn; all beads keep rippling on a continuous wave that travels the garland once per 1.2 s step (on beat with the walk); the
whole garland breathes (scale 1→1.07); and the thread starts its **next random form the moment the gold bead leaves** a bead
(0.5 s morph, settled before it arrives) — a shuffled bag of six shapes (ring, taut hexagon, deep
scallop, big bloom, alternating wave, lobed pairs), each appearing once per walk,
never twice in a row, every one still threading all seven bead centres.
Reduced-motion renders the static mark.

<ThinkingRow label="Reading course files…" />
